    So wird der Text aufgeteilt
    • Eine Leerzeile trennt Abschnitte (Folien).
    • Erste Zeile wie Strophe 1, [Refrain], Chorus:, Bridge, Intro, Schluss → Abschnittsname.
    • 1. Text … am Anfang → Strophe 1.
    • Instrumental / Intro allein in einem Block → leere Folie an dieser Stelle.
    • Nur Refrain ohne Text → Refrain wird an dieser Stelle wiederholt.
    • Blöcke ohne Namen werden fortlaufende Strophen; ein wortgleich wiederholter Block wird als Wiederholung erkannt.
